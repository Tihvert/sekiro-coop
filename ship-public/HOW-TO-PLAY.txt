SEKIRO TOGETHER 1.0.9 beta - quick guide
=============================================

Beta, still buggy. Back up your saves before playing.
Full readme, known bugs and source: https://github.com/Tihvert/sekiro-coop

YOU NEED
- Sekiro on Steam, version 1.06 (normal, unmodded)
- me3 mod loader: https://github.com/garyttierney/me3/releases (default install)
- Windows, or Linux / Steam Deck with Proton (see LINUX / STEAM DECK below)

ONCE
1. Install me3.
2. Got Sekiro Online or other online mods? Delete dinput8.dll, steam_api64.org,
   cream_api.ini and SekiroOnlineFont.ttf from the game folder, then
   Steam > Sekiro > Properties > Installed Files > Verify integrity.
3. Unzip this anywhere EXCEPT the game folder.
4. Start Steam, double-click sekiro-coop.me3 once (me3 starts the game),
   close the game.
   sekiro_coop_settings.ini shows up next to the DLL. If it does not, check
   me3 is installed and your antivirus did not remove sekiro_coop.dll.
5. Put the same password for everyone in the ini (password = ...).
   Co-op is off while it's empty.
6. Everyone needs the exact same mod version.

PLAYING
1. Start Steam, double-click sekiro-coop.me3, load your save.
2. After the intro (Genichiro beats you, you wake up at Dilapidated Temple)
   rest at the temple idol. You get:
   - Kindred Bell   = open your world (host)
   - Kindred Charm  = join the host
   - Severed Thread = leave co-op
3. Host uses the Bell, others use the Charm. Status is in the top left corner.
4. Settings: the ini file or Options > Co-op Settings in game.

STOPPING
1. Everyone uses the Severed Thread, joiners first and host last.
   Joiners get a loading screen and are back in their own world.
2. Then Quit Game from the menu, or Alt+F4.
Quit Game is greyed out while you're still in co-op, that's on purpose.
Don't close the game from Task Manager unless it's frozen. Then the log
can't tell me if it crashed or not. If it froze or crashed, say so in your
report and send log.txt and log.old.txt.

CONNECTION
Steam by default, falls back to direct UDP after 15 s. Steam lobbies only work
when Sekiro is owned on that Steam account and Steam is online; otherwise use UDP.

DIRECT UDP (in [ADVANCED] in sekiro_coop_settings.ini)
Host:
1. transport = udp (or auto, then it switches after 15 s).
2. Load your save and use the Kindred Bell. The address only shows up after
   the Bell, not at game start.
3. The mod tries to open port 28100 UDP on your router (UPnP). If it works,
   the top left shows "join code 1.2.3.4:28100" and the same code is saved
   to udp_join_code.txt next to the ini (deleted when the session closes).
4. No udp_join_code.txt and "UPnP failed" in the top left? Forward UDP 28100
   to your PC by hand in the router, and get your public IP from a site like
   whatismyip.com. Your join code is <that ip>:28100.
5. Send the join code to everyone joining.
Joiners:
1. transport = udp and udp_host_address = <host's join code>,
   e.g. udp_host_address = 1.2.3.4:28100
2. Same password as the host.
3. Load your save and use the Kindred Charm.
Only the host needs an open port. All joiners use the same address.
Can't open ports? A virtual LAN (Radmin VPN, ZeroTier, Tailscale) works:
everyone joins the same network and joiners use the host's VPN IP as
udp_host_address. No port forwarding needed then.

SHARED PICKUPS (share_pickups = 1 in sekiro_coop_settings.ini, default on)
An item one of you picks up from the map while connected (treasure, chests,
items on corpses) is given to the other too, with the small pickup log, and
the other can no longer pick it up there. Both players need share_pickups = 1.
Pickups made alone or before the session stay your own; shops stay your own.
The item disappears from the other's map at once (no glow, no prompt), and a
second pickup of it is refused.
Log lines start with "pickup:".

SAVES
Co-op uses its own save S0000.coop.sl2, your normal save isn't touched.
Backups: %LOCALAPPDATA%\sekiro-coop\save-backups\

BUGS
Log: %LOCALAPPDATA%\sekiro-coop\log.txt
Press F11 (or Back/Share on a pad) when a bug happens, it marks the log.
Report on GitHub with the logs from everyone.

LINUX / STEAM DECK
Not tested on Linux by me yet. me3 supports Linux and the Deck through
Proton, so it should work. Tell me if it does or doesn't.
No WINEDLLOVERRIDES launch option needed, that's only for Sekiro Online.
1. Start Sekiro once from Steam normally, quit at the main menu.
2. Install me3 for Linux (Deck: Desktop Mode, Konsole), see
   https://github.com/garyttierney/me3 for the one-line install.
   "me3 is not available on PATH" is fine, the install worked.
3. Unzip this in your home folder (not the game folder), e.g. ~/Games/sekiro-together
4. Steam running, then in a terminal in that folder:
   ~/.local/bin/me3 launch -p "$PWD/sekiro-coop.me3"
   Starting from the Steam library button starts the game WITHOUT the mod.
5. Rest is the same as above (ini, password, items).
Files: the ini is next to the DLL. Log, backups and saves are in
Sekiro's Proton prefix:
  ~/.local/share/Steam/steamapps/compatdata/814380/pfx/drive_c/users/steamuser/
    AppData/Local/sekiro-coop/   log.txt, save-backups
    AppData/Roaming/Sekiro/      saves
Full Linux guide, Deck Game Mode and fixes for "doesn't start":
https://github.com/Tihvert/sekiro-coop/blob/main/docs/LINUX.md
